# Dashboard-Economico-de-Aportes-2025
El objetivo es analizar los aportes económicos realizados por estudiantes, distribuidos por distrito, curso, sección y otros indicadores relevantes.  El dashboard permite visualizar la información de manera clara, dinámica e interactiva, facilitando la toma de decisiones y el análisis financiero.
